# Project Maverick

Compatibility-first extensions for **The Political Process v0.353**.

Current milestone adds political intelligence QoL, politician operating archetypes, comprehensive multidimensional ideological archetypes for politicians, inferred ideological voter cohorts, candidate-coalition analysis, search/filter/watchlists/recent views, comparison tooling, and an in-game Maverick UI shell.

The original game remains authoritative. Project Maverick does not replace native `.bin` gameplay modules and stores extension state separately. Installation is fail-closed against the verified v0.353 baseline and is reversible through an exact `index.html` backup.

See `docs/INSTALL.md`, `docs/COMPATIBILITY.md`, the design under `docs/superpowers/specs/`, the implementation plan under `docs/superpowers/plans/`, and `docs/verification/v0.353-qol-archetypes-ideology.md`.

The public repository intentionally excludes the upstream commercial executable, assets, redistributables and compiled gameplay bytecode.
