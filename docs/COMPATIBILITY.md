# Compatibility

Initial target: The Political Process v0.353. Pristine `index.html` SHA-256: `6f14224fe1d37240f6bcdd8cb81b1e2305dbdbb3a8bf154afb97c071271878a4`. `node tools/verify-v0353.js <gameDir>` checks all files listed in `baseline/v0.353-code.sha256`, including the native `.bin` modules, HTML, CSS, and package bootstrap. For the known v0.353 hash, the installer invokes this full manifest check itself, then rechecks the exact pristine `index.html` hash immediately before patching. It fails closed when a compatibility file differs.

The loader hook is placed after the last inline native `evalNWBin(...)` call. Installer and build output directories are additive and ownership tracked: existing unknown folders are preserved, modified or untracked installed files block replacement/rollback, and rollback restores the verified index backup only when the installed index still matches its recorded hash. Native `.bin` modules are never written by Project Maverick tooling. Project Maverick state is stored separately under `projectMaverick.state.v1`. Missing runtime globals degrade features to empty/unavailable data and are logged through Project Maverick diagnostics.
